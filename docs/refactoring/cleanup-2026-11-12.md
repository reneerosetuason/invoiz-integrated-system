## Recovery

Before deletion, every target was archived and its archived bytes checked against
the original SHA-256 checksum. The archive is outside the public document root:

`storage/framework/cleanup-recovery-20261112.zip`

The manifest records the archive checksum. To recover a file, extract the archive
to a separate review directory and copy only the required entry back to its
original location. Do not extract over the working tree without reviewing entries.
Root SQL snapshots were archived only; no dump, migration, seeder or financial
action was executed against the application database.
